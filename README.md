# 🚀 Full-Stack Anime Recommendation Engine

This project is a complete, full-stack application that serves intelligent anime recommendations through a RESTful API. It features a machine learning backend built with **Python**, **FastAPI**, and **Scikit-learn**, and a dynamic, responsive frontend built with **React.js**.

The system is capable of generating three distinct types of recommendations:
1.  **Similar Anime** (Content-Based)
2.  **Genre-Based** (Content-Based)
3.  **User-Based** (Collaborative Filtering)

---

## 🏛️ Project Architecture

This application follows a modern, decoupled 3-tier architecture:

1.  **Frontend (React):** A responsive React application (created with `create-react-app`) that acts as the user interface. It manages state, handles user input, and makes API calls to the backend.
2.  **Backend (FastAPI):** A high-performance Python API built with FastAPI. It handles all business logic, validates incoming requests (using Pydantic), and serves predictions from the ML model.
3.  **Model (Scikit-learn):** A set of machine learning models and data artifacts (`.joblib` files) generated by an offline `train.py` script. The model class (`AnimeRecommendationModel`) encapsulates all logic for data loading, preprocessing, and prediction.
[User] --> [React Frontend] --> [FastAPI Backend] --> [Recommendation Model] (localhost:3000) (localhost:8000) (recommendation_model.py)
## ✨ Features

* **Hybrid Recommendation System:** Implements both content-based and collaborative filtering.
    * **Content-Based:** Uses **TF-IDF** for genre vectorization and **Jaccard Similarity** for finding similar anime on-the-fly.
    * **Collaborative Filtering:** Uses a pre-computed **Cosine Similarity** matrix (`similarity.joblib`) to predict user ratings for unseen anime.
* **Robust Search:** Uses `fuzzywuzzy`'s `token_set_ratio` to provide accurate results even with partial or misspelled anime names (e.g., "code geass" matches "Code Geass: Hangyaku no Lelouch").
* **Dynamic React UI:** A clean user interface built with React, featuring:
    * Two distinct pages for "Similar Anime" and "Genre-Based" recommendations.
    * Loading spinners and skeleton cards for a smooth user experience.
    * Error handling for API failures or "not found" messages.
* **External API Integration:** The React frontend fetches anime cover art from the public **Jikan API** (`api.jikan.moe`).
* **Image Caching:** Caches Jikan API image results in the browser's `localStorage` to reduce network requests and improve load times.
* **Efficient Model Loading:** The FastAPI backend uses "lazy loading" for the large model artifacts, ensuring a fast server startup time.

## 🏁 Getting Started

### 1. Prerequisites

* Python 3.9+
* Node.js v18+ and npm
* Git

### 2. Project Setup

**1. Clone the repository:**

```bash
git clone https://github.com/Anas-Tou/AnimeRecModelApiTrained.git
cd your-repo-name
```

**2. Set up the Data:**

* Create a directory named `data/` in the project root.
* Place your `anime.csv` and `rating.csv` files inside this `data/` folder.

**3. Set up the Backend (Python):**

```bash
# Navigate to the backend directory (assuming you have one)
# If all files are in the root, just run these commands from the root
pip install -r requirements.txt 
# or pip install "fastapi[all]" uvicorn scikit-learn pandas joblib fuzzywuzzy
```

**4. Train the Model (Critical Step):**

* Before you can run the API, you must generate the model artifacts.
* Run the `train.py` script from your terminal:

```bash
python train.py
```

* This will create a `model_data/` directory containing `similarity.joblib` and other necessary files.

**5. Set up the Frontend (React):**

```bash
# Navigate to the /frontend directory
cd frontend 
npm install
```

### 3\. Running the Application

You will need two separate terminals to run the backend and frontend simultaneously.

**Terminal 1: Run the Backend (FastAPI)**

```bash
# From the project root (or backend folder)
uvicorn main:app --reload
```

* The API will be running at `http://127.0.0.1:8000`

**Terminal 2: Run the Frontend (React)**

```bash
# From the /frontend directory
npm start
```

* The React app will open in your browser at `http://localhost:3000`

You can now use the application\!
